# bu-ec551-proj1
Programming Assignment 1 – Logic Synthesis Engine

Structure of Repository:
  testdata folder:
  sop0.blif - template for .blif file
  sop[1-?].blif - blif files that are correct, increasing in complexity
  xsop[1-?].blif - incorrect blif files, with errors that should be caught by blif_parser.py
  sop[1-?].txt - text files containing SOP expressions - typically equivalent to the sop[1-?].blif files

blif_parser.py (more info in comments on file itself)
  opens, parses, checks .blif file
  provides error explanations

AI Usage:
None in test files (testdata folder)
